# Лист — debug branch

This branch is used for the modernized Android interface and debug APK testing.

Supported file families currently recognized by the app: DOCX, ODT, XLSX, PPTX, PDF, TXT, RTF, CSV, Markdown, and common images. Some formats are currently opened as plain text; full fidelity editing is being developed incrementally.

The Android debug workflow installs the current Android SDK command-line tools and exposes the legacy `tools/bin/sdkmanager` path required by the pinned python-for-android release.
